# ClipFlow Privacy Policy

**Effective Date:** 2024

ClipFlow is a local, private automation tool for personal content repurposing. This policy explains how data is handled.

## Data We Process
- **YouTube video transcripts** — fetched via YouTube Data API (public videos only)
- **Video files** — processed locally on your machine
- **OAuth tokens** — stored locally in encrypted token store for API access

## Data We Do NOT Collect
- No personal identification information
- No analytics, tracking, or telemetry
- No data sent to our servers (we have none)
- No video content uploaded to third parties except via your authorized OAuth connections

## Third-Party APIs Used
- **Google (YouTube)** — for video metadata and transcripts
- **Gemini AI** — for prompt generation (your API key)
- **Opus Clip** — for clip generation (your API key)
- **Meta (Instagram/Facebook)** — for posting (your OAuth authorization)
- **TikTok** — for posting (your OAuth authorization)

## Data Retention
- OAuth tokens: stored locally until you revoke access
- Processed videos: stored in local `clips/` folder until you delete
- No cloud backup or sync

## Your Rights
- Revoke OAuth access anytime in platform settings
- Delete all local data by removing the ClipFlow app data folder
- No account to delete — we don't have accounts

## Contact
Private tool — no public support channel.
